# Portable AIBI Contract

## 상태 기계

`idle → checkingSession → ready → loading → injecting → submitting → observing → stabilizing → completed`

어느 단계에서나 `needsLogin`, `needsUserAction`, `failed`, `cancelled`로 갈 수 있습니다. 각 작업은 단조 증가하는 `taskId`를 가지며 다른 작업의 콜백을 받지 않습니다.

## 세션

- Apple은 모든 로그인·실행 WebView가 `WKWebsiteDataStore.default()`를 공유합니다.
- Android는 표준 `CookieManager`와 DOM storage를 사용합니다.
- Android 다중 사진은 `${applicationId}.fileprovider`가 노출한 `cache/aibi/`의 정규화 복사본을 `WebChromeClient.onShowFileChooser`로 전달하는 경로를 우선합니다. 실제 콜백 모드가 다중 선택이면 전체 URI를 한 번에 반환하고, 단일 선택이면 선택 순서대로 한 장씩 콜백을 반복합니다. 제공사 DOM의 `input.multiple` 값만으로 네이티브 콜백 모드를 추정하지 않으며, 전송 뒤 의미 기반 첨부 컨트롤의 정확한 개수를 검증합니다. 웹 `DataTransfer`는 보조 경로입니다.
- 인증 판정은 쿠키 존재나 로그인 버튼 부재가 아니라, 제공사별 계정 표식과 로그인·보안 표식의 조합으로 합니다. 로그아웃 공개 화면에도 나타날 수 있는 일반 작성기·`contenteditable`·전송 버튼은 인증 증거로 쓰지 않습니다. 상태는 `확인 중 / 로그인됨 / 로그인 필요 / 확인 안 됨`을 구분하며 제한 시간이 끝난 값을 계속 `확인 중`으로 표시하지 않습니다.
- 상태 확인용 브라우저도 실제 뷰 계층과 실제 화면 좌표에 기준 크기로 붙이고, 앱의 불투명 표면 뒤에 거의 투명하게 둡니다. 0×0, `GONE`, unattached, 수천 px 화면 밖 WebView는 금지합니다.
- 호스트는 명시적인 재확인 동작과 확인 후 전체 AIBI WebView 세션을 지우는 로그아웃 동작을 제공해야 합니다. 세션 삭제 후 각 제공사 행에서 공식 로그인 화면을 다시 열 수 있어야 합니다.
- 앱이 직접 전체 WebView 세션 삭제를 완료한 직후에는 모든 대상 제공사를 `로그인 필요`로 확정 표시합니다. 이 확정 상태는 앱 재시작 뒤에도 유지하고 즉시 자동 프로브의 `확인 안 됨` 결과로 덮어쓰지 않으며, 사용자가 해당 제공사의 로그인 흐름을 열거나 로그인을 완료한 뒤에 다시 프로브합니다. 저장하는 값은 제공사별 명시적 로그아웃 여부뿐이며 계정·쿠키 정보는 저장하지 않습니다.
- 로그인 성공을 확인하면 저장소를 flush하고 성공을 한 번만 알린 뒤 로그인 화면을 자동으로 닫습니다.

## 표시 방식

- 기본값은 `필요할 때만 표시`입니다.
- 숨김 모드는 실제 크기의 비가시 브라우저로 실행하고 호스트 화면에 단계, 남은 시간 역카운터, 줄어드는 가로 진행 바를 표시합니다.
- 숨김 모드에서 신뢰 터치, 문구 입력, 전송 시도가 끝날 때마다 활성 DOM 입력을 blur하고 WebView 포커스를 해제한 뒤 Android 입력기를 닫습니다. 숨김 브라우저 때문에 시스템 키보드만 단독으로 나타나서는 안 됩니다.
- 보이기 모드는 처음부터 브라우저를 표시합니다.
- 로그인, CAPTCHA, 보안 확인, 지속적인 입력 탐색 실패처럼 사용자가 해야 할 일이 있을 때만 숨김 실행을 폐기하고 새 보이는 브라우저로 전환합니다.
- 네트워크·제공자 오류는 사용자가 할 수 있는 행동을 먼저 알려주며, 자동으로 브라우저를 열어 문제를 감추지 않습니다.

## 선택적 미디어 첨부

- 작업은 텍스트 프롬프트 외에 순서가 있는 이미지 첨부 목록을 가질 수 있다. 휴대 가능한 절대 상한은 20장이며 기본 호스트 정책은 8장이다. 20장은 제공자가 보장한 고정 한계가 아니라 호스트가 실험적으로 선택할 수 있는 상한이다. provider 또는 호스트 상한이 더 작으면 작업 시작 전에 명시적으로 거부한다. 첨부 목록과 각 사진의 선택적 역할(예: 전체 모습·라벨·재질·손상·구성품)은 작업 시작 시점에 스냅샷하며 이후 호스트 쪽 미디어 편집이 진행 중인 작업에 섞이지 않는다.
- 호스트는 원본을 변경하지 않고 전송용 사본만 만든다. 기본 정규화 정책은 긴 변 2,048px 이하, JPEG 품질 0.84에서 시작, 장당 2MB 이하이며, 목표 크기를 넘으면 먼저 JPEG 품질을 낮추고 다음으로 해상도를 15%씩 낮춘다. 8장을 넘는 호스트는 총 전송량을 제한하도록 장수별 더 낮은 목표 용량과 긴 변을 명시해야 한다. 모든 변환은 순차 처리해 여러 장의 원본 비트맵을 동시에 유지하지 않는다.
- 첨부는 provider별 capability로 게이팅한다. provider가 이미지 입력을 지원하지 않거나 자동 첨부에 실패하면, 사진을 빼고 텍스트만 조용히 전송해서는 안 된다.
- 자동 첨부는 공개 웹뷰 API만 사용한다: 네이티브 파일 패널 델리게이트가 있고 다중 선택을 허용하는 플랫폼에서는 앱이 만든 임시 파일 URL 목록을 한 번에 전달한다. 그렇지 않으면 provider 자신의 `multiple` 파일 입력에 표준 DOM API(`DataTransfer`/`File`)로 목록 전체를 채운다. 어느 경우든 provider 보안을 우회하거나 자격 증명을 위조하지 않는다.
- 다중 첨부는 원자적이다. 작업 시작 전 미리보기 개수를 기준선으로 기록하고, 요청된 모든 사진만큼 미리보기가 증가한 경우에만 프롬프트 입력·전송으로 넘어간다. 부분 성공, 중복, 순서 손실, provider 상한 초과는 성공으로 취급하지 않는다.
- 자동 첨부가 실패하거나 전부 확인되지 않으면 숨김 실행을 폐기하고, 프롬프트와 아직 전송되지 않은 첨부를 유지한 채 보이는 브라우저로 전환해 사용자가 직접 확인하도록 명확히 안내한다.
- 파일명은 `aibi-01.jpg`처럼 순서를 보존하지만 원본 파일명·위치·EXIF·기타 개인정보성 메타데이터는 전달하지 않는다. 사진의 의미 역할은 파일 메타데이터가 아니라 호스트가 작성한 프롬프트로 설명한다.

## 입력과 전송

- 제공자별 semantic selector 묶음을 사용하고 단일 CSS selector에 의존하지 않습니다.
- textarea/input은 native value setter, contenteditable은 input/beforeinput 이벤트까지 사용합니다.
- 전송은 신뢰 수준을 올리며 시도합니다: 제공자 전송 버튼 → 실제 좌표 터치/클릭 → form submit → native Enter.
- 입력창 비움, 새 assistant node, 생성 표식 중 하나로 실제 전송을 확인한 뒤 관찰로 넘어갑니다.

## 결과 관찰

- 작업 시작 전 assistant 결과들의 노드 식별자와 텍스트를 기준선으로 기록합니다.
- 새 노드뿐 아니라 같은 노드의 텍스트 변화도 후보로 취급합니다.
- 제공자별 완료·중지·오류 표식은 보이는 요소만 인정합니다. DOM에 남은 숨김 spinner는 무시합니다.
- 비어 있지 않은 후보가 생성 중이 아니고 최소 3회 같은 정규화 텍스트로 관찰될 때 완료합니다.
- `pre code`를 우선하고 바깥 코드펜스·단순 머리말·UI 장식을 정리합니다.
- 호스트 결과 sink가 승인한 결과만 정확히 한 번 반영합니다.
- 결과 관찰에는 호스트가 정한 유한한 상한을 둡니다. 기본 상한은 전송 확인 후 119초이며, `1:59 → 0:00` 역카운터와 줄어드는 진행 바로 알립니다. 0에서 작업을 자동 중단하고 짧은 재시도 안내를 표시합니다.
- 숨김·보이기 실행 모두 진행 화면에 항상 `취소` 행동을 제공합니다. 취소는 WebView, 관찰 타이머, taskId를 즉시 무효화하고 사용자가 곧바로 다른 제공자를 선택할 수 있게 합니다.

## 보안과 관찰 가능성

- 허용된 공식 origin에서만 스크립트를 실행합니다. OAuth·결제·제3자 origin에는 주입하지 않습니다.
- 로그에는 프롬프트, 답변, 쿠키, 토큰, 전체 URL query를 남기지 않습니다.
- 기록 가능한 값은 제공자, 단계, 소요 시간, selector family, 익명 실패 코드, 결과 길이입니다.
