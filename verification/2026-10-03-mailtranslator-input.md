# MailTranslator native macOS AIBI 0.5.3 verification

## Failure and repairs

- Native `insertText` smart quote substitution changed structured prompts before send. Escaped literal `insertHTML` retains exact prompt verification and single-shot dispatch. No source markup is interpreted.
- ChatGPT authenticated markers now recognize the observed Korean profile menu and role-button variant. Its current reply renderer lacks the old assistant/markdown classes; a positive `ChatGPT 답변:` / `ChatGPT said:` heading identifies the assistant scope, bounded before another heading or the composer. A semantic stop control is recognized inside the composer scope.
- Code blocks are read through `textContent` before `innerText`.
- Claude OAuth uses a real child WebView with WebKit's configuration, preserving the opener/callback relationship. Existing sign-in completed and the child closed normally. Authentication origins remain allowlisted; children receive no task scripts and are cleaned up on cancellation/teardown. A login-required observation before submission enters the login path.
- A format-rejected or timed-out answer stays in the existing conversation during visible takeover.
- Initial Mail-specific JSON repair changed only narrowly observed delimiters outside quoted values, then required normal JSON parsing and the same key/string/length validation. A subsequent Claude run still produced invalid JSON, so this was not sufficient stability evidence.
- The current Mail host requests plain-text records under unpredictable batch markers. It freezes the batch until completion, rejects unknown/duplicate IDs and premature END, and validates every value before applying text. Quotes and line breaks no longer require AI-generated JSON escaping. A live ChatGPT run showed code language/copy UI contaminating automatic extraction; copying the actual code accepted both body/OCR responses, proving the distinction. The host now applies only the marker-bounded translation values and discards surrounding UI labels. All matching markers still participate in validation. Legacy JSON compatibility remains fail-closed. Owned-draft recognition, batching, consent and result validation remain host-only.
- A repeated Claude run omitted two items. Valid completed items are preserved, while only missing/invalid items stay pending for one same-provider retry; repeated omissions remain visible failures. The four-batch action limit remains, and cancellation/provider/document changes clear retry state. Five subsequent Claude runs passed before the ChatGPT extraction change; they are archived as historical evidence rather than final-candidate passes.

- Gemini returned its exact transient service-error sentence after a completed generation. Only this known error receives one same-provider retry, never authentication, quota, CAPTCHA, ambiguous submit or timeout failures.
- A Gemini OCR response repeated item IDs and was rejected even when copied directly from the website code block. The host now permits one stable completed format rejection to retry pending work on the same provider, within the existing four-batch action budget. Invalid answers are never applied; the final rejected answer stays available for manual takeover. Structured Mail replies bypass generic prose cleanup and are validated by the Mail host itself. Retry failures remain explicit in sanitized evidence.
