# StarManager AIBI Product Profile

이 문서는 스타매니저 전용 요구입니다. 다른 앱에 자동 적용하지 않습니다.

## AIBI에 연결되는 스타매니저 요구

- 제공자 순서: Gemini, ChatGPT, Claude, 기기 AI
- 외부 AIBI 제공자: Gemini, ChatGPT, Claude. 기기 AI는 웹 AIBI가 아닙니다.
- 제공자 카드를 누르면 별도 실행 확인 없이 즉시 시작합니다.
- `브라우저 보기` OFF: 작성 화면을 유지하고 AI 버튼 바로 아래에 단계·경과 시간·취소를 표시합니다.
- `브라우저 보기` ON: 공식 AI 화면을 처음부터 표시하고 완료하면 결과를 가져와 자동으로 닫습니다.
- 로그인 관리: `확인 중 / 로그인됨 / 로그인 필요`. 로그인됨은 초록 원형 체크와 초록 글씨, 로그인 필요는 빨간 행동 표식입니다.
- 로그인 성공이 확인되면 로그인 화면을 자동으로 닫고 상태를 새로 읽습니다.
- 실행 중 진행 카드에는 항상 `취소`를 표시합니다. 전송 확인 후 `남은 시간 1:59`에서 시작하는 역카운터와 줄어드는 가로 진행 바를 표시하고, 0에서 자동 중단한 뒤 다시 시도하도록 안내합니다.
- 생성 결과는 스타매니저의 문체·길이·금칙어·이모지·해시태그·180자 목표 규칙으로 검증합니다.
- 성공한 외부 AI 결과는 클립보드에도 복사하되, 앱 본문 반영을 기준 결과로 삼습니다.
- Claude 카드는 제품에서 승인된 주황색 Claude 아이콘을 사용합니다.
- Android 기기 AI는 플랫폼 공통 공식 로고가 없으므로 스타매니저의 sparkles 아이콘을 사용합니다.
- 작성 화면은 미리보기 패널을 따로 두지 않는 단일 작성 패널입니다. 미디어 선택 → 초안 작성 → AI 요청 → 결과 반영 → (선택) 결과를 다시 다듬어 재요청까지 같은 편집 영역 하나에서 이어집니다. 이 레이아웃은 AIBI 공통 스킬이 아니라 스타매니저 호스트 고유 요구입니다(아래 "AIBI가 아닌 스타매니저 요구" 참고).
- 입력 모드는 모드 선택 UI 없이 자동으로 결정됩니다: 대표 사진만 있으면 사진 기반 지시문을, 대표 사진과 초안 글이 모두 있으면 둘을 함께 반영하라는 지시문을, 글만 있으면 기존 텍스트 전용 문구를 보냅니다.
- 대표 사진은 미디어 목록에서 가장 먼저 선택된 이미지입니다(영상은 대상에서 제외). 요청 시점에 스냅샷해 이후 미디어 편집이 진행 중인 요청에 섞이지 않게 하며, 외부 AI 버튼을 누를 때만 함께 전송됩니다.
- 기기 AI(온디바이스)는 텍스트 전용입니다. 사진만 있고 글이 없는 경우 기기 AI 버튼은 비활성 상태를 유지해 보이지 않는 사진을 본 것처럼 결과를 만들지 않습니다.

## AIBI가 아닌 스타매니저 요구

다음은 스타매니저 제품 기능이며 AIBI 공통 스킬에 넣지 않습니다.

- 앱 업데이트 카드와 자동 다운로드 UI
- 카메라 연속 촬영 및 미디어 순서 편집
- 첫 화면 전체 레이아웃, 탭바, BK/클래식 테마
- 인스타그램 게시물 미리보기와 프리셋

## 배포 연결

- 소비자 명세: `consumers/starmanager.json`
- iOS 배포 스냅샷: `profiles/starmanager/distribution/ios/`
- Android 배포 스냅샷: `profiles/starmanager/distribution/android/`
- 앱 고유 UI, 작성기 상태, 결과 sink는 배포 allowlist에 넣지 않습니다.
- iOS는 현재 엔진과 호스트 UI가 한 파일에 섞여 있으므로 그 파일을 `host-adapted-runtime`으로 관리합니다. 공통 엔진으로 승격하기 전에는 이 스냅샷의 StarManager 동작을 다른 앱의 기본값으로 사용하지 않습니다.
