# DenimDex host profile

Consumers: DenimDex-iOS and DenimDex-Android. The portable runtime/provider registry is shared verbatim. Native split session engines and diagnostic stores remain host-adapted distribution files.

The host owns value-analysis prompts, image roles, validation/result storage, camera guidance, archive data, the Quick Value timeout, screen appearance and authentication presentation. Those are not generic AIBI policy and are not overwritten by distribution.

Version 0.5.0 adds single-shot dispatch, exact pre-send attachment verification, cancellation guards, pending versus actual generation states, and private bounded diagnostic JSON. Settings offers explicit user sharing, with no automatic upload. Stargram's 96-point composer clearance is not a DenimDex layout requirement.

Verification and public release status must be recorded per app, not inferred from shared code or another consumer's successful session.
